# Автопилот Growth Engine

Недельный цикл без участия человека: прогон, отчёт, статус, журнал.

## Что он делает и чего не делает

| Делает | Не делает никогда |
|---|---|
| Собирает Insights из выгрузок студии | Не публикует в соцсети |
| Считает KPI и обновляет growth memory | Не снимает `HOLD` и `FROZEN` |
| Проверяет состояние трёх блокеров | Не трогает canonical state студии |
| Пересобирает бэклог и контент-план | Ничего не удаляет |
| Ведёт журнал прогонов | Не выдаёт `PREDICTED` за `REAL` |

Публикация остаётся решением владельца и проходит через Master Publish Gate
отдельно. Автопилот её не касается.

## Установка на машине студии

```powershell
cd C:\Users\Admin\sofia_growth_engine
.\sofia_growth\autopilot\install_task.ps1 -MediaDir "D:\AI_CONTENT\Sofia\video_ready"
```

Понедельник 08:00 по умолчанию. Другое время и день:

```powershell
.\sofia_growth\autopilot\install_task.ps1 -Day Friday -Time 19:00
```

Проверить сразу, не дожидаясь расписания:

```powershell
Start-ScheduledTask -TaskName SofiaGrowthAutopilot
Get-ScheduledTaskInfo -TaskName SofiaGrowthAutopilot
```

Удалить:

```powershell
.\sofia_growth\autopilot\install_task.ps1 -Uninstall
```

## Что остаётся локально, а что уходит в репозиторий

Репозиторий может быть публичным, поэтому разделение жёсткое:

| Артефакт | Где | Почему |
|---|---|---|
| `reports/autopilot/cycle_*.md` | **только локально** | Полный отчёт с охватом и подписчиками |
| `data/autopilot_log.json` | **только локально** | История прогонов с локальными путями |
| `data/autopilot_status.json` | коммитится при `-Push` | Операционные данные: стадии, вердикт блокеров, счётчики Reels и нарушений формата. Метрик аудитории в нём нет |
| `plans/`, `data/trend_radar.json` | коммитится при `-Push` | Планы и сигналы, не данные аккаунта |

Без `-Push` в репозиторий не уходит ничего — все артефакты остаются на машине.

## Как замыкается петля

С `-Push` статус попадает в ветку, и еженедельная облачная сессия видит,
отработал ли автопилот и сдвинулись ли блокеры, без пересылки метрик аккаунта.

## Запуск вручную

Планировщик не обязателен:

```powershell
python sofia_growth\tools\autopilot.py --studio "D:\AI_CONTENT\Sofia" `
    --media-dir "D:\AI_CONTENT\Sofia\video_ready"
```

Коды возврата: `0` — цикл прошёл полностью, `1` — часть стадий BLOCKED
(обычно нет данных), `2` — стадия упала с ошибкой, смотреть отчёт.

## Оговорка по тестам

Логика автопилота на Python и покрыта прогоном `tests/run_e2e.py`.
`install_task.ps1` — тонкая обёртка над планировщиком; PowerShell в среде
разработки отсутствует, поэтому этот скрипт не прогонялся автоматически.
Он только регистрирует задачу и ничего не вычисляет.
