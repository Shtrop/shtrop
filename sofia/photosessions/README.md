# Фотосессии Sofia — пакет промптов по референсам

Шесть фотосессий по 10 кадров (60 кадров всего). Первые три собраны по присланным референсам — те же наряды, те же позы, те же локации и свет; следующие три развивают ту же визуальную линию в новых сценах. Пакет **не публикует ничего** и не запускает GPU — это только исходники промптов и рендер брифов (`local-only`, `no-publish`).

## Что внутри

```
sofia/photosessions/
├── common/persona_lock.json      # личность Sofia, negative prompt, тех-дефолты, QA-гейты
├── sessions/01_golden_gym.json       # S01 — зал на закате          (референс 1)
├── sessions/02_cozy_night.json       # S02 — уютная ночь дома        (референс 2)
├── sessions/03_neon_selfie.json      # S03 — неоновое селфи          (референс 3)
├── sessions/04_morning_kitchen.json  # S04 — утро на кухне           (развитие 2 и 3)
├── sessions/05_emerald_rooftop.json  # S05 — изумрудный закат        (развитие 1)
├── sessions/06_rainy_hoodie.json     # S06 — дождливый день в худи   (развитие 3)
├── tools/build_prompts.py        # сборка финальных промптов
├── tools/run_session.py          # прогон сессии через ComfyUI и запись PNG
└── build/                        # результат сборки (брифы, .txt промпты, batch.json)
```

Источник истины — файлы в `sessions/` и `common/`. Каталог `build/` пересобирается:

```bash
python3 sofia/photosessions/tools/build_prompts.py
```

### Сессии 4–6 — развитие той же линии

| # | Сессия | Наряд | Ключевой кадр | Свет / локация |
|---|--------|-------|---------------|----------------|
| S04 | Утро на кухне | кремовое oversize худи с плеча + белые шорты + носки | первый глоток капучино у окна | мягкое утро через тюль, белый мрамор и дерево |
| S05 | Изумрудный закат | изумрудный спорт-топ + леггинсы, босиком | наклон вперёд на коврике, взгляд в объектив | терраса на крыше, контровой закат, город внизу |
| S06 | Дождливый день | серое укороченное худи на молнии + белый топ + гольфы | на подоконнике в наушниках, дождь по стеклу | холодный дневной свет + одна тёплая лампа |

S05 намеренно берёт изумруд из канон-палитры персоны, S04 — капучино; S06 выводит наушники в главный маркер кадра.

Каждая сессия строится вокруг хиро-кадра, который повторяет референс один в один; остальные 9 держат тот же наряд, локацию и схему света, но меняют ракурс, оптику и действие — чтобы получилась связная серия, а не 10 копий одного кадра.

Внутри сессии: 2 hero-кадра (по 8 сид-вариантов на отбор), остальные core/filler по 4 варианта.

## Как прогонять в студии

1. Preflight по `sofia-ai-studio-controller`: `control_flags\PUBLISHING_STATE.json`, `NO_DELETE.flag`, `PUBLISHING_DISABLED.flag`, локи, `nvidia-smi`, отсутствие активного `gpu_render`.
2. Подставить реальные значения вместо `TODO_FROM_*` в `common/persona_lock.json` — sampler, вес Sofia LoRA и PuLID берутся из актуальных persona/config файлов студии, здесь они намеренно не выдуманы.
3. Пересобрать: `python3 tools/build_prompts.py`.
4. Прогнать сессию одной командой (одна сессия за раз, один GPU job, по расписанию `gpu_resource_scheduler`):

   ```powershell
   python tools\run_session.py `
       --batch build\golden_gym\batch.json `
       --workflow D:\AI_CONTENT\Sofia\workflows\<ваш_flux_workflow>_api.json `
       --out D:\AI_CONTENT\Sofia\generated\golden_gym
   ```

   Workflow нужен в API-формате (в ComfyUI: Workflow -> Export (API)) — скрипт сам находит в графе
   узлы позитива, негатива, seed и размера кадра и подставляет туда данные из `batch.json`.
   Полезные флаги: `--dry-run` (показать план), `--shots S01-01 S01-07` (только хиро-кадры),
   `--variants 2` (урезать число вариантов), `--server` (если ComfyUI не на `127.0.0.1:8188`).
   Скрипт ничего не публикует и не перезаписывает существующие файлы; итог пишется в
   `<out>\run_manifest.json`.
5. Прогнать `photo_qa` + `identity_guardian` по каждому кадру; FAIL уходит в `photo_regen`, а не заменяется соседним кадром.
6. Публикация — только через Master Publish Gate отдельным решением владельца. Этот пакет её не касается.

## Границы контента

Все 60 кадров — SFW lifestyle/fitness: одежда полностью надета и непрозрачная, никакого explicit. Персона каноническая, 26 лет, без сходства с реальными людьми. Правила и negative prompt зафиксированы в `common/persona_lock.json` (`content_policy`).
